# Security and data-loss reports

For a possible unsafe move, overwrite, directory traversal or data-loss issue, contact **furkiak@gmail.com** privately before posting full paths or a real journal publicly. Include the source revision, a synthetic reproduction and whether files were on the same volume. Do not send private documents or activity logs unless essential.

The app moves local files and cannot provide a backup guarantee. Until a release is verified, test with disposable files only. See [safety notes](docs/SAFETY.md).
